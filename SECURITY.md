# Security and privacy

Spectrum Extraction is an unofficial project. Use it only with your own authorized Universiti Malaya SPeCTRUM session and within applicable university rules. Do not share account credentials, browser data, downloaded course materials, staging reports or identifying information in issues or pull requests.

The crawler is opt-in. It uses a dedicated, loopback-only Edge debugging profile and does not launch a browser or change authorization. Keep that browser profile private: local processes with access to its debugging port can control the profile. Downloaded content remains untrusted. The plugin does not open or execute it. Local output is not encrypted by the plugin.

Report a suspected vulnerability using GitHub's private vulnerability reporting if enabled. If no private channel is available, open an issue requesting one without including vulnerability details or account data. Use synthetic examples for regular bug reports.
